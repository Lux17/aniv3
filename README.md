# Website Anniversary 3 Tahun Pacaran 💕

Website romantis untuk merayakan anniversary 3 tahun pacaran dengan animasi, musik romantis, galeri foto, dan efek hati yang indah.

## Fitur

- ✨ Animasi hati melayang di background
- 💕 Musik romantis yang bisa dinyalakan/matikan
- 💌 Pesan cinta dengan efek typewriter
- 📸 Galeri foto kenangan (bisa ditambahkan foto sendiri)
- 💖 Berbagai animasi romantis
- 📱 Responsive untuk semua perangkat
- 🎨 Desain cantik dengan tema pink romantis

## Cara Menggunakan

### 1. Tambahkan Foto Kenangan
Masukkan foto-foto kalian ke folder `img/` dengan nama:
- `foto1.jpg`
- `foto2.jpg`
- `foto3.jpg`
- `foto4.jpg`
- `foto5.jpg`
- `foto6.jpg`

Bisa ganti nama filenya di `script.js` baris 97-104 jika mau pakai nama yang berbeda.

### 2. Tambahkan Lagu Romantis
Masukkan lagu romantis kalian ke folder `audio/` dengan nama:
- `romantic.mp3`

Bisa ganti nama filenya di `index.html` baris 37.

### 3. Edit Pesan Cinta
Buka `index.html` dan edit bagian message section (baris 75-110) untuk menyesuaikan pesan dengan kalian berdua.

Ganti `[Namamu]` dengan nama kamu di baris 109.

### 4. Buka Website
Cukup buka file `index.html` langsung di browser kamu!

## Teknologi yang Digunakan

- HTML5
- CSS3 (Animasi & Gradient)
- Bootstrap 5
- JavaScript (Vanilla)
- Font Awesome
- Google Fonts

## Tips

- Untuk pengalaman terbaik, gunakan foto dengan ratio persegi atau landscape
- Pastikan ukuran foto tidak terlalu besar biar loading cepat
- Lagu MP3 dengan ukuran < 5MB akan lebih aman
- Website ini 100% client-side, tidak butuh server atau backend

Dibuat dengan 💕 untuk kalian berdua
